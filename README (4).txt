MCA203P - Object Oriented Programming Using Java
LAB SHEET-02

Files:
Q01 to Q30 are separate Java programs corresponding to questions 1-30.

How to run in VS Code:
1. Install JDK (17 or newer recommended).
2. Open this folder in VS Code.
3. Open any Qxx_*.java file.
4. Open Terminal -> New Terminal.
5. Compile:
   javac Q01_Triangle_Area_Heron.java
6. Run:
   java Q01_Triangle_Area_Heron

For another question, replace the filename/class name with the corresponding Qxx file.

OOP structure:
Each program is implemented as a Java class. Static helper methods are used where the problem naturally benefits from encapsulation/reuse. The programs otherwise preserve the exact operator, loop, switch, continue, break, and mixed-advanced concepts requested by the lab sheet.
